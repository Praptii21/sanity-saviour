#  Sanity Saviours

Sanity Saviours is a web-based platform designed to support *healthcare professionals* in managing stress, improving mental well-being, and maintaining a better work-life balance.

---

# Aim
To build a user-friendly and secure platform that helps healthcare workers manage stress, track mental health, and stay organized through wellness tools, communication, and workload management.

---

## ⚙ Features
- 🧩 *Mood Tracker* – Log and monitor daily mood and stress levels  
- 🧠 *Self-Assessment Quiz* – Check burnout and anxiety levels  
- 📅 *Shift Planner & To-Do List* – Organize tasks efficiently  
- 💬 *Peer Support Forum* – Connect anonymously with colleagues  
- 💻 *Responsive Layout* – Works on desktop and mobile  
- 🌗 *Light/Dark Mode* – Saves user theme preference  
- 📝 *Interactive Forms* – With validation and local storage  

---

## 🧰 Tech Stack
*Frontend:* HTML, CSS, JavaScript
